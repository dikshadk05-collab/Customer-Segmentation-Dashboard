Sequential Data Mining Steps

1. Multi-Source Integration

Combines Demographics dataframe with synthetic behavior records on CustomerID.

2. Deduplication

3. Missing Value Imputation

Replaces missing values (NaN) with feature median values.

4. Outlier Removal (IQR)

Filters values outside [Q1 - 1.5*IQR, Q3 + 1.5*IQR] bounds.

5. Feature Scaling & Clustering

Applies StandardScaler prior to fitting K-Means clustering.
